# Support

## Usage help

1. Read [README](README.md), especially requirements, commands, privacy, and troubleshooting.
2. Search [existing issues](https://github.com/arro000/pi-meat/issues).
3. Open bug report with minimal reproduction and environment details.

Community support is best effort. No response-time or backwards-compatibility SLA is provided before stable release.

## Include in report

- pi-meat, Pi, Node.js, Go, Git, OS, and terminal versions;
- install source (`npm`, Git, or local path);
- command/source selector used;
- exact error and reproduction steps;
- whether custom `PI_MEAT_*` variables are set.

Redact source code, diffs, model output, paths, tokens, credentials, and private repository details before posting logs.

## Security

Do not use support issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
