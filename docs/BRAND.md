# pi-meat brand guide

## Name

Use **pi-meat** in prose, package UI, and headings. Use `@andreaarrighi/pi-meat` only for npm package and install commands. Avoid “Pi Meat,” “Pi-Meat,” and claims implying official status.

## Positioning

**Tagline:** Read the change. Skip the gristle.

**One-line description:** Navigable reading diffs for Pi, powered by Meat and your existing Pi model.

**Core promise:** Reduce diff-reading noise while keeping original diff one key away and verification in Pi.

Never claim abridgement proves correctness, replaces review, or prevents model error.

## Voice

- Direct, technical, compact.
- Explain trust boundaries and limitations plainly.
- Prefer “reading diff” over “smart diff” in user-facing copy.
- Capitalize Pi and Meat as project names.
- Avoid gore, aggressive meat jokes, or language that trivializes security/privacy.

## Visual identity

- Dark neutral base.
- Coral accent (`#ee715c`).
- Muted removal red (`#913b44`).
- Muted addition green (`#307a54`).
- Monospace/diff visual language.
- Meat emoji (`🥩`) is optional shorthand, not upstream logo.

Gallery/social preview: `assets/pi-meat-preview.png`. Regenerate with:

